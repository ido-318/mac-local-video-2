# יצירת סרטונים מקומית ב־Mac

החבילה מיועדת ל־Apple Silicon, עם הגדרות התחלה שמרניות למחשב שבתמונה: M5 Pro ו־24GB זיכרון מאוחד. היא משתמשת במודל הפתוח Wan 2.1 T2V 1.3B באמצעות PyTorch ו־Diffusers.

אין חשבון Higgsfield, מפתח API, תשלום לכל יצירה או מכסת קרדיטים. המחשב מריץ את המודל בעצמו. זו חלופה מקומית עצמאית עם יכולות ואיכות משלה. הסרטונים נוצרים ללא קול. המודל לא הותקן ולא הורץ במלואו במהלך הכנת החבילה, ולכן התאימות והביצועים במחשב שלך עדיין טעונים אימות בהפעלה הראשונה.

## התחלה

1. חלצו את החבילה לתיקייה במחשב ופתחו בה Terminal.
2. פנו כ־40GB בדיסק להתקנה, משקלי המודל ותוצרים ראשונים. משקלי המודל לבדם יורדים בהפעלה הראשונה בנפח של כ־29GB. נדרשת רשת להורדה הראשונית בלבד.
3. התקינו את התלויות בסביבה נפרדת בתוך תיקיית החבילה:

```sh
bash setup.sh
```

ההתקנה מאתרת Python תואם בגרסת arm64. אם אין, התקינו Python 3.13 מ־[python.org](https://www.python.org/downloads/macos/) והריצו שוב. אין צורך ב־sudo או בהתקנה כללית של חבילות Python. תוצאת ההתקנה נשמרת ב־`.runtime/installed-versions.txt`.

4. התחילו בסרטון קצר אחד:

```sh
bash run.sh --prompt "A cinematic shot of ocean waves at sunset, warm golden light, slow camera movement"
```

ברירת המחדל היא מצב `preview`: רזולוציה של 512×288, 33 פריימים ב־16 פריימים לשנייה — כ־2.06 שניות — ו־20 צעדי יצירה. זהו מצב לבדיקה ולחיסכון בזמן; הרזולוציה נמוכה מרזולוציית האימון המומלצת ועלולים להופיע פגמים. זמן היצירה על ה־M5 Pro לא נמדד; אל תצפו להבטחת זמן או לאיכות של שירות מסחרי מסוים.

התוצרים נשמרים בתיקיית `videos` ליד הסקריפט. לכל סרטון נשמר קובץ הגדרות וזמן ההרצה בפועל. כך אפשר למדוד את המחשב שלך לפני מעבר לאצווה גדולה.

## אפשרויות

סרטונים מכל התיאורים שבקובץ, אחד בכל שורה:

```sh
bash run.sh --file prompts.txt
```

סרטון ברזולוציה הטבעית של המודל, 832×480, באורך כ־5.06 שניות, עם 50 צעדים:

```sh
bash run.sh --prompt "A red fox walking through a snowy forest, cinematic lighting" --preset 480p
```

סרטון אנכי ברזולוציית 480×832:

```sh
bash run.sh --file prompts.txt --preset 480p --portrait
```

בדיקה קצרה יותר במקרה של עומס זיכרון:

```sh
bash run.sh --prompt "Ocean waves at sunset" --preset preview --frames 17
```

לאחר שהמודל ירד במלואו, הרצה ללא חיבור לרשת:

```sh
bash run.sh --file prompts.txt --offline
```

הורדת המשקלים בלבד:

```sh
bash run.sh --download-only
```

בדיקת התקנה וגישה למעבד הגרפי, ללא הורדת המודל:

```sh
bash run.sh --check
```

בדיקת התיאורים וההגדרות ללא התקנה, ללא הורדה וללא יצירה:

```sh
python3 local_video.py --file prompts.txt --dry-run
```

## זיכרון, מגבלות והמשך עבודה

- מקודד הטקסט נטען בנפרד ומשוחרר לפני טעינת רכיבי יצירת הווידאו. תוצאות קידוד התיאורים נשמרות לשימוש חוזר, ופענוח הפריימים מתבצע באריחים כדי להפחית את צריכת הזיכרון.
- מומלץ לסגור תוכנות כבדות בתחילת העבודה. 24GB הם זיכרון משותף למערכת, ליישומים ולמעבד הגרפי; התאמה מעשית אינה מובטחת בכל הגדרה.
- אין מכסה למספר היצירות שמוכתבת בידי שירות, אבל קיימות מגבלות זמן עיבוד, זיכרון, דיסק וחשמל. למודל עצמו יש חלון תיאור של 512 טוקנים; תיאור ארוך יותר נדחה עם הודעה לקצר אותו. זו מגבלת אורך טקסט, לא יתרת שימוש.
- אנגלית מומלצת לתיאורים. המודל מתועד עבור אנגלית וסינית; איכות ההבנה של עברית אינה מובטחת.
- `--frames` חייב להיות מהצורה 4n+1, למשל 17, 33, 49 או 81. הגדלת מספר הפריימים מגדילה את העומס. `--steps` שולט במספר צעדי היצירה; פחות צעדים חוסכים זמן אך יכולים לפגוע באיכות.
- הרצה חוזרת של אותה פקודה מדלגת על סרטונים שהושלמו ונבדקו. סרטון שנקטע באמצע מתחיל מחדש; אין המשך מאמצע צעדי היצירה. לשונות נוספת באותו תיאור השתמשו למשל ב־`--seed 123`.
- מצב `--offline` דורש שהמשקלים כבר ירדו. קובצי המשקלים וההתקנה נשארים בתוך `.runtime` בחבילה; התיאורים והסרטונים אינם נשלחים לשירות יצירה חיצוני.
- אם בדיקת GPU נכשלת בסביבה מוגבלת, הריצו את הפקודות ב־Terminal של macOS. הסקריפט לא עובר אוטומטית להרצת CPU איטית.
